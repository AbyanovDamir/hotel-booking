# ADR-0003: JWT HS256 и внутренний ключ

Статус: принят для учебного проекта.

Gateway и оба сервиса независимо проверяют JWT, так что обход Gateway не отключает
аутентификацию. HS256 выбран для простого локального запуска; секрет поступает только
из окружения. В production следует перейти на асимметричный ключ и внешний issuer.
Внутренние confirm/release требуют отдельный `X-Internal-Key` и не маршрутизируются
Gateway.
