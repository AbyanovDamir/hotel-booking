# ADR-0004: PostgreSQL на сервис и Flyway

Статус: принят.

Локальный запуск и тесты используют H2. Контейнерная среда использует отдельные
PostgreSQL `booking-db` и `hotel-db`. Схема меняется Flyway-миграциями, Hibernate
работает в режиме `validate`. Общая база отклонена: она нарушает владение данными и
связывает релизы сервисов.
