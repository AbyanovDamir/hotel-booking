# ADR-0002: Retry, timeout и circuit breaker

Статус: принят.

Синхронный Feign-клиент имеет таймауты соединения/чтения 2 секунды. Resilience4j
повторяет временные сбои до трёх вызовов и размыкает цепь при серии ошибок. Повтор
безопасен благодаря `requestId`. Бизнес-конфликты HTTP 409 не повторяются.
